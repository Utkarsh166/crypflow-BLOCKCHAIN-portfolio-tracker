# crypflow-BLOCKCHAIN-portfolio-tracker
“Tired of bloated, ad‑infested crypto trackers flexing SDKs you’ll never use? I said nah — so I built Crypflow.”

Crypflow is a lightweight Solana portfolio tracker built with React Native, Expo & TypeScript, talking straight to the blockchain via raw JSON‑RPC fetch() calls — no wallet‑connect SDK, no dependency circus.

One wallet scan gives you:

✅ Live SOL + token balances

✅ Full transaction history, auto‑classified (swap/deposit/withdrawal)

✅ Portfolio dashboard — value trend + token allocation visualized

✅ Live market cap rankings

✅ Curated NFT showcase + theme switching

✅ Real‑time feed data via APIs, including live SOL → USD price tracking

The constraint — no SDK, just fetch() — forced me to actually understand Solana’s RPC layer instead of hiding behind abstractions. As a learner, that trade is worth it every time.
